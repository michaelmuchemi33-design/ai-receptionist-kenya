Install TWIGA on your device

Open the live workspace first. Browser installation options depend on your device and browser version.

Android phone or tablet

Open live.twiga.co.ke in Chrome. Sign in, open the browser menu, then choose Install app or Add to Home screen if shown.

iPhone or iPad

Open live.twiga.co.ke in Safari. Tap the Share icon and select Add to Home Screen.

Windows, Mac or Linux

Open live.twiga.co.ke in a supported browser. Use the install icon in the address bar or the browser menu's Install page as app option.

Android APK — public beta

Download the TWIGA Android test build. It is debug-signed for testing, not production-signed. Android may ask you to allow installs from your browser.

Common questions

Is this the actual TWIGA app or just a preview?

Both experiences use the same app: the demo host shows illustrative sample records, while the live host requires sign-in and opens your separate workspace.

Will the demo copy sample data into my account?

No. The demo and live workspace use separate modes. Your live workspace starts empty.

Does installing the web app require an app-store account?

No app-store account is needed for the browser-installable version. Use the installation option provided by your device browser.

Is every business feature connected to live services?

The workspace screens are available, but external integrations such as telephone answering, WhatsApp automation, payment providers and email notifications require separate provider configuration and testing before they can be treated as active services.
